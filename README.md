# Portfolio of Agnes Catherine Suico

A modern, premium‑looking portfolio built with **Next.js 16**, **Tailwind CSS**, and **Framer Motion**. It showcases featured projects, certifications, and skills with vibrant purple accents, smooth hover animations, and a dark‑mode aesthetic.

## Features
- Hero section with a clear identity statement.
- Featured Projects with screenshots extracted directly from PDFs.
- Interactive certificate modal powered by Framer Motion.
- Responsive design using Tailwind utilities.
- Dark‑mode ready with a rich gradient palette.

## Getting Started
```bash
# Clone the repo (once you push it to GitHub)
git clone https://github.com/<your‑username>/<repo‑name>.git
cd <repo‑name>

# Install dependencies
npm install

# Run the development server
npm run dev
```

## Deploy
Deploy to Vercel, Netlify, or any platform that supports Next.js. The project builds with `npm run build` and serves static pages.
