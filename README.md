## ✨ Features

- 🎨 **Dark Mode Design** — Deep purple aesthetic with glassmorphism cards and glowing accents
- 🚀 **Smooth Animations** — Scroll-triggered reveals, floating elements, and micro-interactions via Framer Motion
- 💻 **Featured Projects** — Interactive floating laptop mockups with full modal pop-ups (problem, solution, tech stack, gallery)
- 📂 **More Projects** — Clickable cards with "What I Learned" pop-ups
- 🏆 **Certifications** — Interactive modal cards for Credly & Coursera badges
- 🎓 **Education & About** — Clean side-by-side layout with Dean's List recognition
- 📄 **Resume Link** — Direct PDF viewer integration
- 🔗 **Live GitHub/LinkedIn links**
- 🖱️ **Custom cursor** with magnetic hover effect on buttons
- 📱 **Fully Responsive** — Mobile to desktop

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/agnescath/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
